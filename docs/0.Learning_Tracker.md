  * [x] Khởi động Express Server lắng nghe trên port 3000.

  * [x] Hiểu bản chất TS cần compile sang JS trước khi Node.js chạy (`tsc` compiler, `ts-node`).
  * [x] Tự chẩn đoán và sửa lỗi `SyntaxError: Cannot use import statement outside a module`.
  * [x] Phân biệt 2 hệ thống module của Node.js: **CommonJS** (`require`) và **ES Module** (`import`).
* **Key Takeaways/Bug fixes:**
  * **Bug:** Dùng cú pháp `import` (ESM) trong dự án khai báo `"type": "commonjs"` → Node.js báo lỗi.
  * **Fix:** Đổi sang `const express = require('express')` để đồng bộ với chuẩn CommonJS mặc định.
  * TypeScript không chạy trực tiếp trên Node.js — cần bước compile sang JS (hoặc dùng `ts-node` gộp 2 bước).
